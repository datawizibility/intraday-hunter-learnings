- Big gap leaves little room to trap sellers then squeeze up.

- After prior-day loss, took a solid profit when available rather than stretching for a huge day.

### Why sell on gap-up (not hunt day-1 sellers)
| Factor | Read |
|--------|------|
| Prior tape | First real sell after positive/gap-up stretch |
| Retail inventory | Sellers thin / small qty; many already booked |
| Gap-up continuation | If only buyers pile in → downside more likely than a clean seller squeeze |
| vs seller hunt | No need to hunt thin day-1 sellers — **sell with** the structure instead |

### Process lessons
- After first big sell day into a prior uptrend: sellers thin → **don’t hunt them** on the next gap-up; prefer **sell** if gap continues with only buyers.
- Large gap-up reduces room for the classic trap-then-squeeze of shorts.
- Put book: BN near round number (~58,000) is the risk focus when size is heaviest there.
- While both sides still participate, hold thesis; one-sided tape → protect profit.
- Process over hindsight: Aug 4 BN-lead cut was correct by rule even if price later fell from the exit area.
- After a loss day, **book** when a good profit is available — don’t demand maximum momentum.

### Keep permanently
1. First sharp sell after positive/gap-up trend → retail sellers thin (book targets) → **don’t hunt them**; if next gap-up continues with **only buyers** → **sell** more likely.
2. Big gap leaves little room to trap shorts then squeeze — don’t invent that path.
3. Puts with heavy BN size: watch **round-number** breakout risk (e.g. ~58,000).
4. Both sides still in → profit safer; **only one side** left → danger / tighten.
5. Prior-day loss → when good profit appears, **book**; don’t stretch for a “huge” day.
6. Cut-by-rule (BN lead against puts) stays correct even if later tape would have worked — process > hindsight.
